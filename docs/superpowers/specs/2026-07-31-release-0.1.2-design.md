# Release 0.1.2 Design

## Goal

Publish the current `findmyitems` code as version `0.1.2` on GitHub and Modrinth,
with both services referring to the same commit, tag, JAR, and release notes.

## Release Flow

1. Set `mod_version` to `0.1.2` and add the dated `0.1.2` changelog section.
2. Run `./gradlew build` and `./gradlew runGameTest`.
3. Run `./gradlew publishMods -PdryRun` and verify the jar, metadata,
   dependencies, and changelog extraction.
4. Commit the release changes, push `main`, and push tag `v0.1.2`.
5. Create and publish the GitHub release with the built jar attached.
6. Run the real Modrinth publish task with `MODRINTH_TOKEN` and verify the
   resulting version.

## Safety

The Modrinth token is supplied through the environment only. No token is
written to the repository or command output. A missing changelog section or a
failed verification command stops the release before publication.

## Verification

The release is complete only when GitHub reports a published `v0.1.2` release
and Modrinth reports a published `0.1.2` version for project `mPTBl3Fj`.
